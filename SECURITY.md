# Security Policy

## Scope

DNS Optimizer changes only DNS server addresses on Windows network adapters. It does not collect credentials or transmit benchmark history.

Do not report private DNS addresses, logs, backups, or other sensitive network details in a public issue.

## Reporting a vulnerability

For a public repository, use GitHub's private security advisory feature when available. Otherwise contact the repository owner privately with reproduction steps and the affected file or version. Please do not publish an exploitable vulnerability before a fix is available.
